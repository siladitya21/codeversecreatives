Prerequisites & tooling

Foundations

Build the language, tooling and mental model every later phase depends on.

Weeks 1–4
WEEK 1

Modern JavaScript & TypeScript for Angular

Build the language foundation every Angular concept sits on top of.
Start this lesson
You'll Be Able To
  • Read and write idiomatic modern JS/TS without hesitation
  • Follow Angular's own source using its type system
  • Configure a TypeScript project confidently
Topics Covered
  • ES2022+: destructuring, spread/rest, optional chaining, nullish coalescing
  • Modules, Promises & async/await
  • Types, interfaces & generics
  • Union types, narrowing & discriminated unions
  • Classes & decorators — the mechanism Angular is built on
  • tsconfig.json deep dive & strict mode

Hands-on: Convert a small vanilla-JS utility library to strict TypeScript, adding proper types and generics throughout.

WEEK 2

Angular CLI, Tooling & Project Anatomy

Get comfortable with the tools you'll use every day for the rest of the course.
Start this lesson
You'll Be Able To
  • Scaffold, run, build and analyze an Angular project from the CLI
  • Explain what every generated file is for
Topics Covered
  • Installing the Angular CLI & creating a new application
  • The Vite/esbuild-based application builder
  • Project structure: angular.json, main.ts, app config
  • Workspaces, multi-app & shared-library setups
  • Environment configuration & build targets
  • Editor setup, Angular Language Service & DevTools

Hands-on: Scaffold a workspace with two applications and one shared library, and wire up a build script for both.

WEEK 3

Standalone Components & the Angular Mental Model

Learn how Angular assembles an application without NgModules.
Start this lesson
You'll Be Able To
  • Explain how a standalone Angular app bootstraps end to end
  • Reason about the component tree as the UI's source of truth
Topics Covered
  • Bootstrapping with bootstrapApplication
  • Standalone components, directives & pipes
  • Providers & ApplicationConfig
  • Change detection & the render cycle (conceptual overview)
  • Component tree & parent/child relationships
  • Migrating a legacy NgModule app (conceptual walkthrough)

Hands-on: Bootstrap a standalone app from scratch (no CLI schematic) and render a three-level component tree.

WEEK 4

Component Fundamentals & Templates

Build your first real components and internalize Angular's template syntax.
Start this lesson
You'll Be Able To
  • Build components with typed inputs/outputs
  • Read and write Angular templates fluently
Topics Covered
  • Component decorator options (selector, template, styles)
  • Interpolation, property & event binding
  • input(), output() & model() signal-based APIs
  • Template reference variables
  • ng-template & ng-container
  • Lifecycle hooks & signal-based alternatives

Hands-on: Build a reusable rating-stars component with a two-way bound value via model().

Core Reactivity & UI

Weeks 5–8
WEEK 5

Signals Deep Dive

Master Angular's fine-grained reactivity primitive.
Start this lesson
You'll Be Able To
  • Model derived and effectful state with signals confidently
  • Avoid common signal pitfalls (over-computing, effect loops)
Topics Covered
  • signal(), computed() & effect() in depth
  • linkedSignal() for dependent, resettable state
  • Signal equality functions & custom comparators
  • untracked() and when to use it
  • Debugging signals with Angular DevTools
  • Signals vs. RxJS — when to reach for each

Hands-on: Build a shopping-cart state model entirely with signals — totals, discounts and item count all as computed signals.

WEEK 6

New Control Flow & Template Syntax

Replace structural directives with Angular's built-in control flow.
Start this lesson
You'll Be Able To
  • Write templates using @if/@for/@switch fluently
  • Understand @for's tracking behavior and why it matters
Topics Covered
  • @if / @else if / @else
  • @for, track expressions & performance implications
  • @switch / @case / @default
  • @let for local template variables
  • Conditional rendering patterns & empty states
  • Migrating *ngIf/*ngFor templates to the new syntax

Hands-on: Rebuild a data table (sorting, filtering, empty state) using only the new control-flow syntax.

WEEK 7

Styling, View Encapsulation & Content Projection

Compose flexible, reusable UI components.
Start this lesson
You'll Be Able To
  • Choose the right encapsulation strategy for a component
  • Build components that accept projected content and slots
Topics Covered
  • Component styles & :host / :host-context
  • View encapsulation modes (Emulated, ShadowDom, None)
  • Host bindings & host listeners
  • ng-content, multi-slot projection & fallback content
  • Responsive layout with the Angular CDK Layout module
  • Building a small design-system component (button, card, modal)

Hands-on: Build a modal component with a named header/body/footer projection API and CDK-based focus trapping.

WEEK 8

Directives, Pipes & the Angular CDK

Extend Angular's template language with your own reusable behavior.
Start this lesson
You'll Be Able To
  • Write custom attribute and structural directives
  • Use the CDK for common UI behaviors instead of reinventing them
Topics Covered
  • Custom attribute directives & host bindings
  • Custom structural directives — how *ngIf-style directives work
  • Pure vs. impure pipes, and building your own
  • CDK Overlay, Portal & DragDrop basics
  • CDK a11y utilities (FocusTrap, LiveAnnouncer)
  • When to build vs. reach for a library

Hands-on: Build a custom "clickOutside" directive and a reusable pipe library (currency, relative-time, truncate).
