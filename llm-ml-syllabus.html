Before You Start

Prerequisites & tooling

What you should already know

  • Basic Python — variables, functions, loops, lists/dicts
  • Comfort with high-school-level math (we refresh what's needed)
  • No prior machine learning or deep learning experience required
  • Python 3.10+ and a code editor installed

Stack you'll work with

From notebooks to a shipped app — the same tools used in industry today.

Python 3.11 NumPy & Pandas scikit-learn PyTorch Hugging Face LangChain Vector Databases Claude & OpenAI APIs Jupyter
Syllabus

Your 16-week learning path

Thirteen modules that build from math and classical ML to transformers, fine-tuning, RAG, agents and a deployed capstone.

01
WEEKS 1–2

Math & Python Foundations

Build the toolkit every later module depends on.

  • Linear algebra & probability essentials for ML
  • NumPy & Pandas for data manipulation
  • Environment setup: venv/conda & Jupyter
02
WEEKS 3–4

Core Machine Learning Concepts

Learn the vocabulary and workflow behind every ML model you'll ever train.

  • Supervised vs. unsupervised learning
  • Train/validation/test splits, bias–variance tradeoff
  • Your first models with scikit-learn
03
WEEK 5

Classical ML Algorithms

The workhorse algorithms behind most tabular-data systems.

  • Decision trees, random forests & gradient boosting
  • Support vector machines
  • Clustering (k-means) & dimensionality reduction (PCA)
04
WEEK 6

Neural Network Foundations

Understand what's really happening inside a neural net.

  • Perceptrons, activation functions & backpropagation
  • Loss functions & optimizers (SGD, Adam)
  • Building your first network in PyTorch
05
WEEKS 7–8

Deep Learning Architectures

Move from single networks to the architectures behind vision and sequence models.

  • CNNs for image data
  • RNNs, LSTMs & an intro to attention
  • Regularization & normalization techniques
06
WEEK 9

Transformer Architecture Deep Dive

The architecture behind every modern LLM, built from first principles.

  • Self-attention & multi-head attention
  • Positional encoding, encoder/decoder stacks
  • Build a mini transformer from scratch
07
WEEK 10

Large Language Model Fundamentals

How raw text becomes a model that can converse and reason.

  • Pretraining objectives & tokenization (BPE)
  • Scaling laws & model families
  • Reading a model card critically
08
WEEK 11

Fine-Tuning & Adaptation

Adapt a pretrained model to your own task and data.

  • Transfer learning & full fine-tuning
  • Parameter-efficient tuning: LoRA & QLoRA
  • Instruction tuning & an overview of RLHF/DPO
09
WEEK 12

Prompt Engineering & Reasoning

Get reliable, structured behavior out of a model without touching its weights.

  • Prompt patterns, few-shot & chain-of-thought
  • Structured outputs & tool schemas
  • Systematically evaluating prompts
10
WEEK 13

Retrieval-Augmented Generation & Embeddings

Ground model answers in your own data.

  • Embeddings & vector similarity
  • Chunking strategies & vector databases
  • Build a working RAG pipeline end-to-end
11
WEEK 14

Agents, Tool Use & Orchestration

Let a model take actions, not just generate text.

  • Function calling & tool-use loops
  • Multi-agent systems & the Model Context Protocol
  • Agent memory & state management
12
WEEK 15

Evaluation, Safety & Deployment

Take a model from a notebook to something you can trust in production.

  • Evals, benchmarks & hallucination mitigation
  • Guardrails & responsible-AI basics
  • Cost, latency & serving considerations
13
WEEK 16 · CAPSTONE

Capstone: Ship an LLM-Powered Application

Combine fine-tuning, RAG, agents and evaluation into one deployed product.

  • End-to-end AI application, from data to deployment
  • Code review & deployment walkthrough
  • Portfolio-ready project you can show employers

Ready to build with LLMs?

Start with Week 1 and work through math, classical ML, deep learning and modern LLM engineering — or check out the Angular course if you're focused on frontend engineering.
