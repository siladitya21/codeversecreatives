Go from Python to production LLMs in one guided path

Start with math and classical machine learning, build up through neural networks and transformers, then fine-tune, prompt, retrieve and orchestrate real large language models — finishing with a deployed AI application.

1

Math & Python Foundations

Build the toolkit every later phase depends on.

Weeks 1–4
WEEK 1

Python Data Science Toolchain

Get a reproducible environment and the two libraries every dataset passes through.
Start this lesson
You'll Be Able To
  • Set up and reproduce a working Python data-science environment
  • Clean, merge and visually inspect a real dataset before modeling it
Topics Covered
  • Reproducible environments: venv/conda & Jupyter
  • NumPy arrays, broadcasting & vectorization
  • Pandas DataFrames, filtering & grouping
  • Handling missing data & merging tables
  • Exploratory visualization with Matplotlib

Hands-on: Clean, merge and visualize a messy two-table student dataset with missing values.

WEEK 2

Linear Algebra & Probability for ML

The two mathematical ideas underneath every model from here on.
Start this lesson
You'll Be Able To
  • Compute matrix multiplication and cosine similarity by hand and in NumPy
  • Apply Bayes' theorem and explain what softmax does to raw scores
Topics Covered
  • Vectors, matrices & matrix multiplication
  • Norms, distance & cosine similarity
  • Probability foundations: distributions, mean & variance
  • Conditional probability & Bayes' theorem
  • Softmax: turning scores into a probability distribution

Hands-on: Build a tiny document search engine with cosine similarity, softmax and Bayes' theorem.

WEEK 3

Statistics for Machine Learning

Reason about whether a difference in the numbers is real, or just noise.
Start this lesson
You'll Be Able To
  • Run and interpret a hypothesis test without misreading the result
  • Explain what a confidence interval actually claims
Topics Covered
  • Descriptive statistics: mean, median, variance, percentiles
  • Common distributions: normal, binomial, Poisson
  • Sampling, the Central Limit Theorem & standard error
  • Hypothesis testing, p-values & common pitfalls
  • Confidence intervals & correlation vs. causation

Hands-on: Given an A/B test dataset, compute a confidence interval and run a hypothesis test to decide whether an observed lift is real.

WEEK 4

Data Wrangling & Feature Engineering

Turn a raw, messy dataset into model-ready features with a repeatable pipeline.
Start this lesson
You'll Be Able To
  • Build a leakage-free preprocessing pipeline for mixed data types
Topics Covered
  • Feature scaling: standardization vs. min-max normalization
  • Encoding categorical variables: one-hot, ordinal, target encoding
  • Handling outliers & skewed distributions
  • Building pipelines with scikit-learn's Pipeline/ColumnTransformer
  • Data leakage: what it is and how it silently inflates results

Hands-on: Build a scikit-learn pipeline that cleans, encodes and scales a mixed dataset, and prove no leakage exists across the train/test split.

2

Core Machine Learning

Learn the vocabulary and workflow behind every ML model you'll ever train.

Weeks 5–8
WEEK 5

The Supervised Learning Workflow

Run a complete supervised-learning experiment, start to finish.
Start this lesson
You'll Be Able To
  • Diagnose whether a model is over- or underfitting, and fix it
Topics Covered
  • Supervised vs. unsupervised vs. reinforcement learning
  • Train/validation/test splits — why three sets, not two
  • The bias–variance tradeoff
  • Overfitting & underfitting: causes and fixes
  • Baseline models & your first scikit-learn classifier/regressor

Hands-on: Train a baseline and an improved classifier on the same dataset, diagnose over/underfitting via learning curves, and fix it.

WEEK 6

Model Evaluation & Hyperparameter Tuning

Choose the right metric for a problem, and tune without leaking test data.
Start this lesson
You'll Be Able To
  • Pick a metric that actually reflects the problem, not just accuracy
Topics Covered
  • Classification metrics: precision, recall, F1, confusion matrix
  • ROC/AUC & when accuracy is misleading (imbalanced classes)
  • Regression metrics: MAE, MSE, RMSE, R²
  • Cross-validation strategies (k-fold, stratified)
  • Grid search & random search for hyperparameters

Hands-on: Tune a model with grid search under proper cross-validation, and justify your metric choice for an imbalanced dataset.

WEEK 7

Unsupervised Learning & Dimensionality Reduction

Explore unlabeled data and reduce dimensionality without losing signal.
Start this lesson
You'll Be Able To
  • Cluster unlabeled data and judge whether the clusters mean anything
Topics Covered
  • k-means clustering & choosing k (elbow method, silhouette score)
  • Hierarchical clustering
  • PCA: variance explained & choosing components
  • t-SNE/UMAP for visualization (conceptual overview)
  • Combining PCA with a downstream supervised model

Hands-on: Cluster an unlabeled dataset, visualize it in 2D with PCA, and evaluate cluster quality with silhouette score.

WEEK 8

Classical ML Mini-Project

Independently scope, build and evaluate a full ML solution end to end.
Start this lesson
You'll Be Able To
  • Take a real dataset from raw files to an evaluated, explained model solo
Topics Covered
  • Framing a real-world problem as an ML task
  • Choosing and justifying a model family
  • Full pipeline: EDA → preprocessing → modeling → evaluation
  • Communicating results with metrics, plots & a short write-up
  • Common failure modes and how to debug them

Hands-on: Pick a public tabular dataset, build a complete evaluated ML pipeline solo, and write a one-page results summary.

Classical ML Algorithms

The workhorse algorithms behind most tabular-data systems.

Weeks 9–10
WEEK 9

Tree-Based Models & Gradient Boosting

Build, tune and interpret the models behind most tabular ML.
Start this lesson
You'll Be Able To
  • Train, tune and explain a gradient-boosted model's predictions
Topics Covered
  • Decision trees: splits, impurity & overfitting
  • Random forests & bagging
  • Gradient boosting fundamentals & XGBoost/LightGBM in practice
  • Feature importance & partial dependence
  • When tree ensembles beat (or lose to) linear models

Hands-on: Train and compare a random forest and a gradient-boosted model, and explain the top features driving predictions.

WEEK 10

SVMs, Naive Bayes & Ensemble Methods

Choose among a wider set of classical algorithms based on data shape and assumptions.
Start this lesson
You'll Be Able To
  • Pick an algorithm family based on dataset size, dimensionality & linearity
Topics Covered
  • Support vector machines & the kernel trick
  • Naive Bayes & its independence assumption
  • Bagging vs. boosting vs. stacking
  • Voting/ensemble classifiers combining different model types
  • Interpretability tradeoffs across algorithm families

Hands-on: Build a stacked ensemble combining an SVM, a Naive Bayes model and a tree ensemble, and measure whether stacking helps.

4

Neural Networks & Deep Learning

Understand what's really happening inside a neural net, then build the architectures behind vision and sequence models.

Weeks 11–14
WEEK 11

Neural Network Foundations

Explain and implement the mechanics of a neural network from scratch.
Start this lesson
You'll Be Able To
  • Implement forward and backward passes of a small network by hand
Topics Covered
  • Perceptrons & the limits of linear models
  • Activation functions: sigmoid, ReLU, softmax
  • Loss functions: cross-entropy, MSE
  • Backpropagation & the chain rule, by hand
  • Gradient descent, learning rate & convergence

Hands-on: Implement a two-layer neural network's forward and backward pass in raw NumPy, and train it on a toy dataset.

WEEK 12

Training Deep Networks with PyTorch

Build, train and debug a real neural network with a modern framework.
Start this lesson
You'll Be Able To
  • Diagnose and fix a network that "isn't learning"
Topics Covered
  • PyTorch tensors, autograd & the training loop
  • Optimizers: SGD, momentum, Adam
  • Regularization: dropout, weight decay, early stopping
  • Batch normalization & learning rate schedules
  • Reading training/validation curves to diagnose problems

Hands-on: Train a multi-layer network in PyTorch, applying at least two regularization techniques and comparing validation curves.

WEEK 13

Convolutional Neural Networks

Build and train a CNN for image classification.
Start this lesson
You'll Be Able To
  • Fine-tune a pretrained CNN and explain what each layer does
Topics Covered
  • Convolutions, kernels, stride & padding
  • Pooling layers & spatial downsampling
  • Classic architectures & a look at ResNet
  • Data augmentation & transfer learning with a pretrained CNN
  • Visualizing what a CNN has learned (feature maps)

Hands-on: Fine-tune a pretrained CNN on a small image dataset and visualize its learned feature maps.

WEEK 14

Sequence Models: RNNs, LSTMs & an Intro to Attention

Process ordered data, and see why attention was invented to fix RNNs' limits.
Start this lesson
You'll Be Able To
  • Explain why transformers replaced RNNs for most sequence tasks
Topics Covered
  • RNNs & the vanishing gradient problem
  • LSTMs & GRUs: gates and why they help
  • Sequence-to-sequence modeling & the bottleneck problem
  • Attention as a fix: a first, intuitive look
  • Where RNNs still make sense vs. where transformers took over

Hands-on: Train an LSTM on a text-sequence task and compare its behavior to a simple attention-augmented variant.

5

Transformers & LLM Foundations

The architecture behind every modern LLM, built from first principles.

Weeks 15–18
WEEK 15

The Attention Mechanism

Implement scaled dot-product and multi-head attention from scratch.
Start this lesson
You'll Be Able To
  • Implement multi-head attention and verify it against a reference output
Topics Covered
  • Queries, keys & values
  • Scaled dot-product attention, step by step
  • Multi-head attention & why multiple heads help
  • Self-attention vs. cross-attention, and attention masks
  • Computational cost of attention & why sequence length matters

Hands-on: Implement scaled dot-product and multi-head attention in raw NumPy/PyTorch and verify against a known reference.

WEEK 16

The Full Transformer Architecture

Assemble a complete transformer block and explain every component's role.
Start this lesson
You'll Be Able To
  • Build a small transformer end-to-end and train it on real text
Topics Covered
  • Positional encoding (sinusoidal & learned)
  • Encoder & decoder stacks
  • Residual connections & layer normalization
  • Encoder-only vs. decoder-only vs. encoder-decoder architectures
  • Building a mini transformer end to end

Hands-on: Build a small decoder-only transformer from scratch and train it on a tiny text corpus to generate plausible text.

WEEK 17

LLM Pretraining & Tokenization

How raw text becomes training data for a model that can converse and reason.
You'll Be Able To
  • Train a tokenizer and reason about vocabulary-size tradeoffs
Topics Covered
  • Byte-Pair Encoding (BPE) & subword tokenization
  • Pretraining objectives: causal LM vs. masked LM
  • Building & inspecting a training corpus
  • Context windows & how they constrain a model
  • Compute & data requirements, at a high level

Hands-on: Train a BPE tokenizer on a custom corpus, inspect how it splits unusual words, and measure vocabulary-size effects.

WEEK 18

Scaling Laws, Model Families & Reading Model Cards

Choose a model using published evidence, not vibes.
You'll Be Able To
  • Read a model card critically and pick a model for a given budget/task
Topics Covered
  • Scaling laws: params, data & compute tradeoffs
  • Overview of major model families & their design choices
  • Open-weight vs. closed models
  • Reading a model card critically (training data, limitations, intended use)
  • Benchmark leaderboards & their limitations

Hands-on: Compare three model cards for models you might use later in this course, and write a short recommendation.

6

Adapting & Directing LLMs

Adapt a pretrained model to your own task and get reliable behavior out of it.

Weeks 19–22
WEEK 19

Fine-Tuning & Transfer Learning

Adapt a pretrained model to a new task via full fine-tuning.
You'll Be Able To
  • Fine-tune a model on custom data and evaluate it against the base model
Topics Covered
  • Transfer learning: freezing vs. fine-tuning layers
  • Full fine-tuning workflow for an LLM
  • Dataset preparation for fine-tuning
  • Catastrophic forgetting & how to mitigate it
  • Compute cost of full fine-tuning at scale

Hands-on: Fine-tune a small open-weight model on a custom instruction dataset and evaluate it against the base model.

WEEK 20

Parameter-Efficient Tuning & RLHF/DPO

Adapt a large model cheaply, and understand how preference-based training works.
You'll Be Able To
  • Fine-tune a model on limited hardware using LoRA
Topics Covered
  • LoRA: low-rank adapters, explained and implemented
  • QLoRA & quantization for memory-efficient tuning
  • Instruction tuning
  • RLHF (reward models & PPO) and DPO as a simpler alternative
  • Choosing full fine-tuning vs. LoRA vs. prompting

Hands-on: Apply LoRA to fine-tune a model on limited hardware, and compare output quality/cost against the Week 19 full fine-tune.

WEEK 21

Prompt Engineering & Reasoning

Get reliable, structured behavior out of a model without touching its weights.
You'll Be Able To
  • Systematically design and evaluate prompts instead of guessing
Topics Covered
  • Prompt structure & system/user/assistant roles
  • Few-shot prompting & chain-of-thought
  • Structured outputs & tool/function schemas
  • Prompt injection risks & mitigations
  • Systematically evaluating and iterating on prompts

Hands-on: Design and evaluate three prompt variants for a structured-extraction task, measuring accuracy against a labeled test set.

WEEK 22

Retrieval-Augmented Generation & Embeddings

Ground model answers in your own data.
You'll Be Able To
  • Build a working RAG pipeline end to end
Topics Covered
  • Embeddings & vector similarity (building on Week 2)
  • Chunking strategies for long documents
  • Vector databases & approximate nearest-neighbor search
  • Retrieval quality: recall vs. precision tradeoffs
  • Evaluating a RAG system's answers for groundedness

Hands-on: Build an end-to-end RAG pipeline over a small document set, from chunking through retrieval to a grounded answer.

Agents, Evaluation & Deployment

Weeks 23–25
WEEK 23

Agents, Tool Use & Orchestration

Let a model take actions, not just generate text.
You'll Be Able To
  • Build a tool-using agent with basic loop protection
Topics Covered
  • Function calling & tool-use loops
  • Designing tool schemas a model can use reliably
  • The Model Context Protocol (MCP)
  • Multi-agent systems, orchestration & agent memory

WEEK 24

Evaluation, Safety & Guardrails

You'll Be Able To

Topics Covered
  • Building evals & benchmarks for your own use case
  • Hallucination detection & mitigation strategies
  • Guardrails, content filtering & responsible-AI basics
  • LLM-as-judge evaluation patterns
  • Informally red-teaming a model

Hands-on: Build a small eval suite for the Week 22 RAG system, including a hallucination check, and report pass/fail results.

WEEK 25

Deployment, Cost & Latency

Take a model from a notebook to something you can trust and afford in production.
You'll Be Able To

Topics Covered
  • Serving options: hosted APIs vs. self-hosted inference
  • Latency/throughput tradeoffs & batching
  • Cost modeling for LLM usage at scale
  • Caching & prompt/response optimization
  • Monitoring, rollback & versioning for a deployed LLM app

Hands-on: Deploy the Week 23 agent or Week 22 RAG pipeline behind an API, log cost/latency, and find one real optimization.
