Section A — Question 1

(a) OOP is a programming paradigm based on the concept of "objects," which bundle data and the methods that operate on that data. Two features: encapsulation (bundling data and methods, hiding internal detail) and inheritance (a class acquiring properties of another class) — also accept polymorphism or abstraction.

(b) Any two: a constructor has the same name as the class, a method can have any valid name; a constructor has no return type (not even void), a method must have a return type; a constructor is invoked automatically when an object is created using new, a method must be called explicitly.

(c) The static keyword marks a member (variable or method) as belonging to the class itself rather than to any individual object, so it is shared across all instances and can be accessed without creating an object. Example: public static void main(String args[]) — the JVM calls main without ever creating an object of the class.

(d) Scanner requires import java.util.Scanner;. BufferedReader requires import java.io.*; (or specifically import java.io.BufferedReader; along with InputStreamReader).

(e) x starts at 5. ++x (pre-increment) makes x = 6 and evaluates to 6. x++ (post-increment) evaluates to the current value of x (6), then increments x to 7. So y = 6 + 6 = 12, and the final value of x is 7. Output: 7 12.

(f) Data type: boolean. Default value for an uninitialized instance variable: false.

(g) Function overloading means defining multiple methods with the same name in the same class, but with different parameter lists (different number or types of parameters). Example: void add(int a, int b) and void add(double a, double b, double c).

(h) 25 = 16 + 8 + 1 → 11001 in binary.

(i) A wrapper class converts (wraps) a primitive data type into an object, so it can be used where an object is required (e.g., in collections). The wrapper class for int is Integer.

(j) Math.pow(2, 3) = 8.0, Math.sqrt(16) = 4.0. Sum = 12.0.

Question 2 — Employee Class
Employee.java
class Employee
{
    String name;
    double basicSalary;

    Employee(String n, double b)
    {
        name = n;
        basicSalary = b;
    }

    double calculateSalary()
    {
        double hra = 0.20 * basicSalary;
        double da = 0.10 * basicSalary;
        return basicSalary + hra + da;
    }

    void display()
    {
        System.out.println("Name: " + name);
        System.out.println("Basic Salary: " + basicSalary);
        System.out.println("Gross Salary: " + calculateSalary());
    }

    public static void main(String args[])
    {
        Employee e = new Employee("Aditi Sharma", 30000);
        e.display();
    }
}

Output: Gross Salary = 30000 + 6000 (20% HRA) + 3000 (10% DA) = 39000.0.

Question 3 — Vowels & Consonants
VowelConsonantCount.java
import java.util.Scanner;

class VowelConsonantCount
{
    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter a sentence:");
        String str = sc.nextLine();
        str = str.toUpperCase();
        int vowels = 0, consonants = 0;

        for (int i = 0; i < str.length(); i++)
        {
            char ch = str.charAt(i);
            if (ch >= 'A' && ch <= 'Z')
            {
                if (ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U')
                    vowels++;
                else
                    consonants++;
            }
        }
        System.out.println("Number of vowels: " + vowels);
        System.out.println("Number of consonants: " + consonants);
    }
}

Question 4 — Largest & Second Largest
LargestSecondLargest.java
import java.util.Scanner;

class LargestSecondLargest
{
    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        int arr[] = new int[10];
        System.out.println("Enter 10 integers:");
        for (int i = 0; i < 10; i++)
            arr[i] = sc.nextInt();

        int largest = Integer.MIN_VALUE, secondLargest = Integer.MIN_VALUE;
        for (int i = 0; i < 10; i++)
        {
            if (arr[i] > largest)
            {
                secondLargest = largest;
                largest = arr[i];
            }
            else if (arr[i] > secondLargest && arr[i] != largest)
            {
                secondLargest = arr[i];
            }
        }
        System.out.println("Largest: " + largest);
        System.out.println("Second Largest: " + secondLargest);
    }
}

Question 5 — Bubble Sort
BubbleSort.java
import java.util.Scanner;

class BubbleSort
{
    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        int arr[] = new int[10];
        System.out.println("Enter 10 integers:");
        for (int i = 0; i < 10; i++)
            arr[i] = sc.nextInt();

        for (int i = 0; i < 9; i++)
        {
            for (int j = 0; j < 9 - i; j++)
            {
                if (arr[j] > arr[j + 1])
                {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }

        System.out.println("Sorted array:");
        for (int i = 0; i < 10; i++)
            System.out.print(arr[i] + " ");
    }
}

Question 6 — Menu: Prime / Armstrong
MenuPrimeArmstrong.java
import java.util.Scanner;

class MenuPrimeArmstrong
{
    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("MENU");
        System.out.println("1. Check Prime Number");
        System.out.println("2. Check Armstrong Number");
        System.out.println("Enter your choice:");
        int choice = sc.nextInt();

        System.out.println("Enter a number:");
        int n = sc.nextInt();

        switch (choice)
        {
            case 1:
                boolean isPrime = true;
                if (n < 2)
                    isPrime = false;
                for (int i = 2; i <= Math.sqrt(n); i++)
                {
                    if (n % i == 0)
                    {
                        isPrime = false;
                        break;
                    }
                }
                if (isPrime)
                    System.out.println(n + " is a Prime number.");
                else
                    System.out.println(n + " is not a Prime number.");
                break;

            case 2:
                int temp = n, sum = 0, digits = String.valueOf(n).length();
                while (temp > 0)
                {
                    int digit = temp % 10;
                    sum += Math.pow(digit, digits);
                    temp /= 10;
                }
                if (sum == n)
                    System.out.println(n + " is an Armstrong number.");
                else
                    System.out.println(n + " is not an Armstrong number.");
                break;

            default:
                System.out.println("Invalid choice.");
        }
    }
}
